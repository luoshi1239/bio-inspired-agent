# bio-inspired-agent

> 生物启发式 AI Agent 架构体系 — 从自然界偷师，设计更好的 Agent 系统。

一个可直接使用的 Agent Skill。涵盖六大生物启发模式、六大设计原则，以及可落地的操作手册。

## 六大模式

| 模式 | 核心思想 | 适合场景 |
|------|---------|---------|
| 🐝 **蜂群智能** | 无中心、分布式、价值敏感共识 | 方案探索、多方向对比、群体决策 |
| 🐜 **蚁群 Stigmergy** | 环境介导协调、信息素痕迹 | 任务路由、共享记忆、团队协作 |
| 🧠 **选择性遗忘 (FadeMem)** | 差异化衰减、冷热分层 | 记忆管理、信息过载、注意力机制 |
| 🛡️ **免疫系统 (ANIS)** | 六层防御、持续免疫学习 | 安全防御、质量控制、对抗进化 |
| 🐦 **Boids 鸟群** | 分离 / 对齐 / 聚合三规则 | 多 Agent 步调协调 |
| 🔄 **递归多智能体** | 递归深化 > 堆叠扩展 | 深度推理、复杂问题求解 |

## 六大设计原则

1. **递归深化 > 堆叠扩展** — 10 个 Agent 递归协作可能胜过 100 个并行堆叠
2. **环境介导 > 直接通信** — 通过共享状态间接协调，避免通信复杂度爆炸
3. **选择性遗忘 > 全量记忆** — 记忆的价值不在记住多少，而在能否快速找到相关的
4. **异构性 > 同质性** — 不同能力的 Agent 组合优于复制同一个
5. **价值敏感 > 简单投票** — 高质量方案应获得更高权重，而非一人一票
6. **涌现设计 > 顶层规划** — 给简单局部规则，让全局行为自底涌现

## 怎么用

### 作为 Agent Skill 使用

把整个目录放进你的 Agent skills 目录即可。支持 SKILL.md 格式的 Agent 框架（Hermes Agent、Claude Code 等）都能直接加载。

```bash
git clone git@github.com:luoshi1239/bio-inspired-agent.git
cp -r bio-inspired-agent ~/your-agent/skills/
```

### 作为方法论参考

直接读 `SKILL.md`。每个模式都有：生物原理 → Agent 映射 → 落地方式 → 适用场景。

不知道该用哪个模式？看主文档的「模式选择指南」，按问题类型查表。

- **RecursiveMAS** (Stanford/MIT/UIUC/HKUST, 2026) — 递归多智能体，准确率 +8.3%，Token ↓34.6~75.6%
- **AMRO-S** (2026) — 蚁群优化 LLM 路由，4.7x 加速，可解释性强
- **FadeMem** (2025) — 生物启发遗忘机制，存储减少 45%，检索性能反而提升
- **ANIS** (2026) — Agent 原生免疫系统，六层防御塔
- **SOHM** (ETH Zurich, 2025) — 小模型蜂群协作超越大模型单体
- **Boids** (Craig Reynolds, 1986) — 群体行为三规则
