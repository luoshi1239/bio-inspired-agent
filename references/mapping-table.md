# 生物概念 → Agent 系统 映射对照表

## 蜂群智能

| 生物概念 | 生物含义 | Agent 映射 | 实现方式 |
|---------|---------|-----------|---------|
| 摇摆舞（Waggle Dance） | 侦察蜂通过舞蹈传递食物源/巢址的方向、距离、质量 | 子Agent提交方案时自带信心分/质量分 | 输出格式加"信心: 0-100"字段 |
| 舞蹈强度 ∝ 质量 | 越好的巢址，跳舞时间越长、重复次数越多 | 高质量方案获得更高权重/更多资源 | 权重系统：质量越高，被引用/合并的概率越大 |
| 分叉动态（Bifurcation） | 当一个方案显著更好时，群体迅速达成共识 | 当某个方案胜率超过阈值，停止探索，收敛 | 收敛阈值：比如连续3轮同一方向最优 |
| 侦察蜂 | 探索新选项的个体 | 多样性工蜂，专门负责试新方向 | 至少保留1个工蜂探索非主流方向，防局部最优 |
| 群体感应（Quorum Sensing） | 当足够多蜜蜂选择同一巢址，就定下来 | 当足够多Agent选择同一方案，就采纳 | 投票阈值 + 质量加权 |

## 蚁群优化 / Stigmergy

| 生物概念 | 生物含义 | Agent 映射 | 实现方式 |
|---------|---------|-----------|---------|
| 信息素（Pheromone） | 蚂蚁在路上留下的化学物质，引导后续蚂蚁 | 路径权重/成功率标记 | 每条路由/路径一个计数器 |
| 信息素蒸发 | 时间久了信息素会挥发，旧路径慢慢被遗忘 | 长期不用的路径权重衰减 | 定期衰减：30天不用权重减半 |
| 正反馈 | 走的蚂蚁越多，信息素越浓，吸引更多蚂蚁 | 成功率高的路径优先被选，越选越准 | 成功+1，失败-0.5 |
| Stigmergy | 通过修改环境间接协调，不直接通信 | Agent通过共享文件/状态协调，不互相发消息 | 共享日志、共享测试集、共享状态文件 |
| 最短路径涌现 | 没有蚂蚁在"算"最短路径，但群体自动找到 | 没有总控在规划，但最优工作流自动浮现 | 信息素浓度可视化 = 自动发现的工作流 |

## 选择性遗忘 / 记忆

| 生物概念 | 生物含义 | Agent 映射 | 实现方式 |
|---------|---------|-----------|---------|
| 艾宾浩斯遗忘曲线 | 新学的东西忘得快，反复用的记得久 | 新记忆衰减快，高频记忆衰减慢 | 差异化衰减率 |
| 工作记忆 | 短时记忆，容量小（7±2），用完就忘 | 会话上下文，单次会话有效 | 会话结束清理 |
| 长时记忆 | 容量大，存储时间长 | 持久记忆 / 知识库 | memory 工具 / 文件系统 |
| 记忆巩固 | 反复使用的信息从工作记忆转长时记忆 | 高频信息从上下文升入持久记忆 | 多次引用的信息自动写入memory |
| 主动遗忘 | 不是被动遗忘，是主动清除干扰信息 | 主动清理低价值记忆，给重要的腾空间 | 记忆整理流程 |
| 记忆提取 | 需要时从长时记忆召回 | 需要时从档案读入热点层 | "详见XXX.md"指针 |

## 免疫系统

| 生物概念 | 生物含义 | Agent 映射 | 实现方式 |
|---------|---------|-----------|---------|
| 物理屏障（皮肤） | 第一道防线，阻挡病原体进入 | 沙箱、隔离、输入过滤 | 沙箱环境、输入校验 |
| 先天免疫 | 快速响应，模式识别，不针对特定病原体 | 硬规则检测、签名匹配 | 硬规则表（固定规则集） |
| 适应性免疫 | 针对新病原体产生抗体，有记忆 | 学习新模式，加新规则 | 对抗进化：发现新类型→加新规则 |
| 免疫记忆 | 得过一次病就不会再得（或更轻） | 遇到过的问题快速识别 | 规则永久保留在规则库 |
| 疫苗 | 弱化的病原体，用来训练免疫系统 | 测试集、对抗样本 | 用难的测试集提前训练规则 |
| 集体免疫 | 群体中足够多个体免疫，疾病就传不开 | 足够多Agent有防御，整体安全 | 一个Agent学到的规则同步给所有 |
| 自身免疫 | 攻击自身细胞=疾病 | 误判真人写的=假阳性 | 防误伤条款、豁免逻辑 |

## Boids 鸟群

| 生物概念 | 生物含义 | Agent 映射 | 实现方式 |
|---------|---------|-----------|---------|
| 分离（Separation） | 别撞到邻居 | 别做别人已经做过的事 | 开工前检查共享状态，跳过已完成 |
| 对齐（Alignment） | 跟邻居速度一致 | 保持推理节奏和深度一致 | 统一输出格式、统一术语、统一深度 |
| 聚合（Cohesion） | 别掉队，往群体中心靠 | 别跑偏，围绕共同目标 | 每轮检查是否还在解决原问题 |
| 涌现（Emergence） | 简单局部规则产生复杂全局行为 | 简单Agent规则产生复杂协作 | 给简单规则，不给全局规划 |

## 递归多智能体

| 生物概念/算法 | 含义 | Agent 映射 | 实现方式 |
|-------------|------|-----------|---------|
| 递归深化 | 同一组函数反复调用自己，每轮深入一层 | 同一组Agent反复循环，每轮深化推理 | 3-5轮递深化，每轮传摘要 |
| 潜空间传递（Latent State Transfer） | 不用原始数据，用压缩表示传递 | Agent间传摘要/关键状态，不传全文 | 输出摘要格式：结论+依据+下一步 |
| 递归 vs 迭代 | 递归=自调用，迭代=循环 | 递归多智能体=同一组Agent循环深化 | for循环调用同一套Agent，传入上一轮输出 |

## 通用原则

| 生物原理 | 含义 | Agent 设计启示 |
|---------|------|---------------|
| 去中心化 | 没有指挥中心，个体自主决策 | 不要总控Agent，让子Agent自主判断 |
| 局部信息 | 个体只知道周围的事，不知道全局 | 每个Agent只看相邻的输入/输出，不读全局 |
| 正反馈 | 好的东西被放大，坏的东西被削弱 | 成功路径加权，失败路径衰减 |
| 适应性 | 环境变了，群体行为跟着变 | 任务变了，分工和路径自动调整 |
| 鲁棒性 | 死几只蚂蚁/蜜蜂不影响群体 | 挂几个Agent不影响整体结果 |
| 简单规则→复杂行为 | 个体规则简单，群体行为复杂 | 给Agent简单的局部规则，不要全局规划 |
